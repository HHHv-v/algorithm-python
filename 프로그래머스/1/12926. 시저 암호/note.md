접근
문자를 하나씩 순회하며 공백은 그대로 두고,
알파벳은 아스키 코드를 n만큼 밀어서 새 리스트에 담은 뒤 join.
대문자와 소문자는 시작 코드가 달라 따로 처리.

처음에 조건문으로 공백과 문자를 처리해야겠다고 생각함
대문자 소문자를 나눌 생각을 못함 z다음에는 a가 와야하는데 A로 와야한다고 착각 (문제 꼼꼼히 읽기)

그래서 처음에는 z=122를 기준으로 공백/122를 넘는지 안넘는지로 구분해버림.

시간 복잡도
O(n)

막힌 지점
- 아스키 순환 계산 원리 — (ord(c) - ord('a') + n) % 26 + ord('a')
  a를 0으로 맞춰야 % 26의 결과 범위(0~25)와 일치함. (ex z+6=f라면 122-97+6=25+6=31%26=5+a=f)
- 공백 비교를 `""`로 씀 
- 계산 결과가 숫자인데 chr로 되돌리지 않아 join에서 TypeError.
- for 줄 콜론 누락.

다른 풀이
- % 대신 넘어갈 때만 26을 빼는 방식도 가능.
  code = ord(c) + n / if code > ord('z'): code -= 26
- ord(c) < 97 대신 isupper() / islower()로 판별하면 의도가 명확함.
  이 경우 공백은 어느 조건에도 안 걸려 자동으로 그대로 남음.
- list(s)로 바꿔 s[i]에 직접 대입하는 방식도 가능.
  단 이때는 for c in s를 쓸 수 없음 (c에 대입해도 원본이 안 바뀜).
