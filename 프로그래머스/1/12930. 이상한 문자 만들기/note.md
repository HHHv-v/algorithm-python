📝 풀이

접근
공백 개수를 유지해야 하므로 split(" ")로 나눈다.
각 단어를 리스트로 바꿔 인덱스 기준으로 짝수는 대문자, 홀수는 소문자로 변환한 뒤
"".join으로 단어를 복원하고, 마지막에 " ".join으로 전체를 합친다.

시간 복잡도
O(n)

막힌 지점
- split()과 split(" ")의 차이를 몰라 한참 헤맴.
  split(" ")는 공백 1개마다 자르고 구분자는 결과에서 사라진다.
  공백이 붙어 있으면 그 사이에 글자가 없어 빈 문자열 ''이 생긴다.
    "a  b".split(" ")   → ['a', '', 'b']      공백 2칸 → 빈 문자열 1개
    "a   b".split(" ")  → ['a', '', '', 'b']  공백 3칸 → 빈 문자열 2개
  ''는 공백이 아니라 "글자 없음"이다. (' '는 길이 1, ''는 길이 0)
  join은 요소 사이에만 구분자를 넣으므로(요소 개수 - 1),
  빈 문자열이 남아 있으면 원래 공백 개수가 그대로 복원된다.
  split()은 연속 공백을 하나로 묶어 그 정보가 사라진다.

- 처음에 if word == " "로 공백을 걸러내려 했으나 의미 없는 조건이었다.
  split(" ") 결과에는 공백 문자가 요소로 들어오지 않고 ''만 들어온다.
  ''는 len이 0이라 range(0)이 되어 반복문이 돌지 않고,
  "".join([])이 ''를 반환하므로 조건 없이도 처리된다.

- replace로 위치 기준 치환을 시도함.
  replace는 값 기준이라 같은 글자가 여러 개면 전부 바뀐다.
    "aba".replace("a", "A")  → 'AbA'   0번째만 바꾸려 했는데 2번째까지 바뀜
  위치 기준으로 바꾸려면 list로 변환 후 word[i]에 대입해야 한다.

- list(word)를 안쪽 반복문에 둬서 매번 실행됨. 바깥으로 빼야 한다.

처음 작성한 코드
- if word == " " 조건으로 공백을 따로 처리하려 했고,
  list(word)가 안쪽 반복문 안에 있었다.
  동작은 했지만 조건이 무의미했고 변환도 매번 일어났다.

다른 풀이
한 줄로 압축한 버전:
  " ".join(map(lambda x: "".join([a.lower() if i % 2 else a.upper()
            for i, a in enumerate(x)]), s.split(" ")))
  - enumerate: 인덱스와 값을 함께 꺼냄
  - 리스트 컴프리헨션: for문으로 리스트를 만드는 한 줄 표기
  - map: 모든 요소에 함수를 적용
  - a if 조건 else b: 삼항 연산자 (TS의 조건 ? a : b와 순서가 다름)
  - if i % 2: 0은 거짓, 0이 아니면 참
  아직 정리 안 한 문법 — enumerate, 리스트 컴프리헨션, map
