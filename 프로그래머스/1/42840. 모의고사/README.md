## 📝 풀이

### 접근
세 수포자의 답안 패턴은 각각 길이 5, 8, 10으로 고정되어 반복된다.
`i % len(패턴)`으로 인덱스를 순환시키면 정답 배열 길이와 무관하게
패턴을 계속 이어 붙일 수 있다.

정답 배열을 한 번 순회하며 세 명의 점수를 동시에 집계하고,
최고점을 구한 뒤 그 점수를 받은 사람의 번호를 순서대로 담아 반환한다.
앞에서부터 순회하므로 결과는 자동으로 오름차순이 된다.

### 시간 복잡도
O(N). 정답 배열 최대 길이 10,000이므로 여유롭다.

### 막힌 지점
- 패턴 배열이 정답 배열보다 짧을 때 어떻게 반복시킬지 몰랐음
  → 나머지 연산 `i % len(pattern)`으로 인덱스 순환
- `for x in list`로는 인덱스를 알 수 없어 패턴 위치를 계산할 수 없음
  → 위치가 필요하면 `range(len())` 또는 `enumerate()`
- 변수명을 `max`로 지정 — 내장 함수 이름을 덮어쓰게 되므로 피해야 한다
  (`list`, `sum`, `len`, `min`, `dict`, `str`, `input` 등도 동일)

### 다른 풀이
최댓값 탐색은 `max(o)` 한 줄로 대체 가능하다.
단, 최댓값이 여러 개인 경우를 찾는 것은 별도 순회가 필요하다.
