# 02-3 리스트 자료형

리스트는 가변(mutable)이다. 문자열과 달리 요소를 직접 수정·삭제할 수 있다.
따라서 리스트 메서드(`append`, `sort`, `reverse`, `insert`, `remove`, `extend`)는
**원본을 바꾸고 `None`을 반환**한다. 결과를 변수에 다시 대입하면 안 된다.

```python
a = [3, 1, 2]
a.sort()        # O — a는 [1, 2, 3]
a = a.sort()    # X — a는 None이 됨
```

|                        | 문자열 (불변)   | 리스트 (가변)          | 튜플 (불변)             |
| ---------------------- | --------------- | ---------------------- | ----------------------- |
| 요소 수정 `x[0] = ...` | 불가            | 가능                   | 불가                    |
| 메서드 동작            | 새 값 반환      | 원본 변경, `None` 반환 | `count`, `index`만 있음 |
| 결과 사용법            | `s = s.upper()` | `a.sort()` 후 `a` 사용 | 새로 만들어 대입        |

<br>

## 리스트 만들기

대괄호로 감싸고 요소는 쉼표로 구분한다. 어떤 자료형이든 담을 수 있다.

```python
a = []                          # 빈 리스트
a = [1, "hi", [2, 3]]           # 자료형 섞기 가능
```

`list()`도 빈 리스트를 만들지만, 보통 **다른 자료형을 리스트로 변환**할 때 쓴다.

```python
list("abc")        # ['a', 'b', 'c']
list(range(5))     # [0, 1, 2, 3, 4]
```

<br>

## 인덱싱과 슬라이싱

기본 문법은 문자열과 같다. (→ string.md)

### 중첩 리스트

```python
a = [1, 2, 3, ['a', 'b', 'c']]
a[-1]         # ['a', 'b', 'c']
a[-1][0]      # 'a'

a = [1, 2, ['a', 'b', ['Life', 'is']]]
a[2][2][0]    # 'Life'

a = [1, 2, 3, ['a', 'b', 'c'], 4, 5]
a[2:5]        # [3, ['a', 'b', 'c'], 4]
a[3][:2]      # ['a', 'b']
```

<br>

## 리스트 연산

```python
a = [1, 2, 3]
b = [4, 5, 6]
a + b         # [1, 2, 3, 4, 5, 6]         이어붙이기
a * 3         # [1, 2, 3, 1, 2, 3, 1, 2, 3] 반복
```

숫자와 문자열은 바로 더할 수 없다. 타입을 맞춰야 한다.

```python
a = [1, 2, 3]
a[2] + "hi"         # TypeError
str(a[2]) + "hi"    # '3hi'
```

<br>

## 수정과 삭제

문자열과 결정적으로 다른 부분이다.

```python
a = [1, 2, 3]
a[1] = 9      # 수정 — [1, 9, 3]
del a[1]      # 삭제 — [1, 3]

a = [1, 2, 3, 4, 5]
del a[2:]     # 슬라이싱으로 여러 개 삭제 — [1, 2]
```

## 메서드와 내장 함수 — sort와 sorted

둘 다 정렬하지만 호출 방식과 동작이 다르다.

```python
a.sort()       # 메서드 — 대상 뒤에 점을 찍고 호출
sorted(a)      # 내장 함수 — 괄호 안에 대상을 넣어 호출
```

**메서드**는 그 객체에 속한 기능이다. 객체 자신을 대상으로 동작하므로,
객체가 가변이면 자기 자신을 직접 고칠 수 있다.
`sort()`는 리스트에만 있는 메서드이고, 리스트가 가변이라 원본을 바꾼다.

**내장 함수**는 특정 객체에 속하지 않고, 값을 인자로 받아 처리한다.
`sorted()`는 문자열·튜플·리스트 등 무엇이든 받을 수 있는데,
문자열이나 튜플은 불변이라 고칠 수 없다. 그래서 항상 **새 리스트를 만들어 반환**한다.

```python
a = [3, 1, 2]

a.sort()          # 반환값 None, a는 [1, 2, 3]
b = sorted(a)     # a는 그대로, b에 정렬된 새 리스트

sorted("cab")     # ['a', 'b', 'c']   문자열도 가능
"cab".sort()      # AttributeError — 문자열에는 sort 메서드가 없음
```

정리하면:

|                | `a.sort()`    | `sorted(a)`         |
| -------------- | ------------- | ------------------- |
| 종류           | 리스트 메서드 | 내장 함수           |
| 사용 가능 대상 | 리스트만      | 순회 가능한 모든 것 |
| 원본           | 바뀜          | 그대로              |
| 반환값         | `None`        | 정렬된 새 리스트    |

> 기준은 "메서드냐 함수냐"가 아니라 **대상이 가변이냐 불변이냐**다.
> 문자열 메서드 `upper()`는 메서드지만 문자열이 불변이라 새 값을 반환한다.

내림차순은 둘 다 `reverse=True`를 넣는다.

```python
a.sort(reverse=True)
b = sorted(a, reverse=True)
```

`reverse()`와 `reversed()`도 같은 구조다.

```python
a = [1, 2, 3]
a.reverse()             # 원본 뒤집기, 반환값 None
b = list(reversed(a))   # 새로 만듦 (list()로 감싸야 리스트가 됨)
b = a[::-1]             # 슬라이싱으로도 가능, 새 리스트
```

## 리스트 메서드

모두 **원본을 바꾼다** (`pop`, `index`, `count` 제외).

**1) 맨 뒤에 추가 — append**

```python
a = [1, 2]
a.append(3)          # [1, 2, 3]
a.append([4, 5])     # [1, 2, 3, [4, 5]]   리스트가 통째로 요소 하나가 됨
```

**2) 여러 개 추가 — extend**

```python
a = [1, 2]
a.extend([3, 4])     # [1, 2, 3, 4]        요소가 하나씩 추가됨
```

`a.extend([3, 4])`는 `a += [3, 4]`와 같다. `append`와의 차이에 주의.

**3) 위치 지정 삽입 — insert**

`insert(위치, 값)`

```python
a = [1, 2, 3]
a.insert(0, 4)       # [4, 1, 2, 3]
```

**4) 값으로 삭제 — remove**

첫 번째로 나오는 값 하나만 삭제한다. 없으면 `ValueError`.

```python
a = [1, 2, 3, 1, 2, 3]
a.remove(3)          # [1, 2, 1, 2, 3]
```

**5) 꺼내기 — pop**

요소를 삭제하면서 **그 값을 반환**한다.

```python
a = [1, 2, 3]
a.pop()       # 3 반환, a는 [1, 2]     인자 없으면 맨 뒤
a.pop(0)      # 1 반환, a는 [2]        인덱스 지정
```

스택은 `append` + `pop()`으로 구현한다.

**6) 위치 찾기 — index**

값이 처음 나오는 위치를 반환한다. 없으면 `ValueError`.

```python
a = [1, 2, 3]
a.index(3)    # 2
```

**7) 개수 세기 — count**

```python
a = [1, 2, 3, 1]
a.count(1)    # 2
```

## 자주 쓰는 내장 함수

메서드가 아니라 괄호에 넣어 호출한다. 원본은 바뀌지 않는다.
리스트·튜플·문자열 모두에 쓸 수 있다.

```python
a = [3, 1, 2]

len(a)        # 3       길이
sum(a)        # 6       합
max(a)        # 3       최댓값
min(a)        # 1       최솟값
2 in a        # True    포함 여부
5 not in a    # True
```

## 02-4 튜플 자료형

**튜플의 요솟값은 한 번 정하면 지우거나 변경할 수 없다.**
그 외에는 리스트와 동일하게 동작한다. 괄호 `()`를 쓴다.

```python
t1 = ()
t2 = (1,)                     # 요소가 하나면 쉼표 필수 — (1)은 그냥 정수 1
t3 = (1, 2, 3)
t4 = 1, 2, 3                  # 괄호 생략 가능
t5 = ('a', 'b', ('ab', 'cd')) # 중첩 가능
```

### 변경 불가

```python
t = (1, 2, 3)
t[0] = 9      # TypeError
del t[0]      # TypeError
```

불변이라 `sort`, `append`, `remove` 같은 원본 변경 메서드가 없다.
메서드는 `count`와 `index`만 있다.

```python
t = (1, 2, 1)
t.count(1)    # 2
t.index(2)    # 1
```

### 인덱싱과 슬라이싱

```python
t1 = (1, 2, 'a', 'b')
t1[0]         # 1
t1[3]         # 'b'
t1[1:]        # (2, 'a', 'b')
```

### 연산

원본을 바꾸는 게 아니라 **새 튜플을 만든다.**

```python
t1 = (1, 2, 'a', 'b')
t2 = (3, 4)

t1 + t2       # (1, 2, 'a', 'b', 3, 4)
t2 * 3        # (3, 4, 3, 4, 3, 4)
len(t1)       # 4
```

### 실전에서 쓰이는 곳 — 다중 대입과 스왑

괄호를 생략한 튜플이 뒤에서 동작한다.

```python
a, b = 1, 2       # 다중 대입
a, b = b, a       # 스왑 — 임시 변수 없이 교환

def f():
    return 1, 2   # 여러 값 반환도 튜플
x, y = f()
```
