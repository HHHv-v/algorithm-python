## 🎯 학습 우선순위

코딩 테스트 출제 빈도를 기준으로 다음 순서로 학습한다.

### 1순위 — 대부분의 코딩 테스트를 커버하는 핵심 영역

| 유형 | 선행 자료구조 | 풀이 수 |
| :--- | :--- | ---: |
| 시뮬레이션 / 구현 | 배열, 문자열 | 0 |
| 완전 탐색 | 재귀, 순열·조합 | 0 |
| 해시 | 해시맵, 해시셋 | 0 |
| 정렬 | 정렬 기준 설계 | 0 |
| DFS / BFS | 스택, 큐, 그래프 | 0 |

### 2순위 — 1순위 숙달 이후 확장

| 유형 | 선행 개념 | 풀이 수 |
| :--- | :--- | ---: |
| 동적 계획법 (DP) | 완전 탐색 | 0 |
| 다익스트라 | BFS, 우선순위 큐 | 0 |
| 이분 탐색 | 정렬 | 0 |
| 위상 정렬 | 그래프 | 0 |

> 2순위는 1순위의 확장이다. DP는 완전 탐색을, 다익스트라는 BFS와 큐를 기반으로 한다.

## ⏱ 시간 복잡도 기준

제약 조건(N의 범위)으로부터 사용 가능한 알고리즘을 역산한다.  
기준은 **1초당 약 10⁸회 연산**이다.

| N의 범위 | 허용 시간 복잡도 | 대표 접근 |
| :--- | :--- | :--- |
| N ≤ 20 | O(2ⁿ), O(N!) | 완전 탐색, 비트마스킹 |
| N ≤ 100 | O(N³) | 플로이드-워셜 |
| N ≤ 1,000 | O(N²) | 이중 반복문, DP |
| N ≤ 100,000 | O(N log N) | 정렬, 이분 탐색, 힙 |
| N ≤ 10,000,000 | O(N) | 선형 순회, 투 포인터 |

## 🛠 주요 활용 라이브러리

| 모듈 | 용도 |
| :--- | :--- |
| `collections` | `deque`(BFS), `defaultdict`(인접 리스트), `Counter` |
| `heapq` | 우선순위 큐, 다익스트라 |
| `bisect` | 정렬된 배열의 이분 탐색 |
| `itertools` | 순열, 조합, 곱집합 |
| `math` | 최대공약수, 조합 계산 |

## 🔁 반복 구현 패턴

시험장에서 시간을 낭비하지 않도록 아래 패턴은 체화한다.

- 간선 리스트 → 인접 리스트 변환
- DFS 재귀 / BFS 큐 기본 골격
- 방문 처리 배열 관리 (반복 실행 시 초기화 주의)
- 노드 식별자가 문자열이거나 범위가 클 경우 배열 대신 해시맵 사용
- 단방향 / 양방향 그래프에 따른 간선 추가 분기
- 그리드(격자) 문제를 그래프로 치환하는 방식
