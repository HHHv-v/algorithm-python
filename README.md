## 📝 학습 규칙

1. 1일 2문제를 기본 단위로 한다.
2. 30분간 자력으로 시도한 후, 해결되지 않으면 타인의 풀이를 참고한다.
3. 참고한 문제는 익일에 아무것도 보지 않고 재풀이한다.
4. 각 문제의 `README.md`에 막혔던 지점과 개선 방향을 기록한다.
