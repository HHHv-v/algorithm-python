# algorithm-python

프로그래머스 기반 코딩 테스트 문제 풀이 저장소
언어는 Python 3를 사용하며 풀이는 [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub)를 통해 자동 커밋

<br>

## 🗂 디렉터리 구조

```
algorithm-python/
├── 프로그래머스/
│   └── <레벨>/
│       └── <문제번호. 문제명>/
│           ├── <문제명>.py      # 제출 코드 (BaekjoonHub 자동 커밋)
│           ├── README.md        # 문제 설명 (자동 생성, 제출 때마다 덮어써짐)
│           └── note.md          # 풀이 기록 (직접 작성)
├── notes/                       # 문법·개념 정리
│   ├── string.md                # 문자열, f-string 포매팅, 진법 변환
│   ├── list.md                  # 리스트, zip, 튜플
│   ├── dict-set.md              # 딕셔너리, 집합
│   ├── function.md              # 함수, lambda, 재귀
│   ├── method-vs-function.md    # 메서드와 내장 함수
│   └── time-complexity.md       # 시간 복잡도
├── course/                      # 수업 실습 (COMP0333, lab01~)
├── NOTES.md                     # C++ ↔ Python 대응, deque 정리
└── README.md
```

> 작업 전 `git pull` 필수 — BaekjoonHub이 원격에 직접 커밋한다.

## 🎯 학습 우선순위

코딩 테스트 출제 빈도를 기준으로 다음 순서로 학습한다.

### 1순위 — 대부분의 코딩 테스트를 커버하는 핵심 영역

| 유형 | 선행 자료구조 | 풀이 수 |
| :--- | :--- | ---: |
| 시뮬레이션 / 구현 | 배열, 문자열 | 8 |
| 완전 탐색 | 재귀, 순열·조합 | 2 |
| 해시 | 해시맵, 해시셋 | 2 |
| 정렬 | 정렬 기준 설계 | 4 |
| 그리디 | 탐욕적 선택의 근거 | 1 |
| DFS / BFS | 스택, 큐, 그래프 | 0 |

### 2순위 — 1순위 숙달 이후 확장

| 유형 | 선행 개념 | 풀이 수 |
| :--- | :--- | ---: |
| 동적 계획법 (DP) | 완전 탐색 | 0 |
| 다익스트라 | BFS, 우선순위 큐 | 0 |
| 이분 탐색 | 정렬 | 0 |
| 위상 정렬 | 그래프 | 0 |

> 2순위는 1순위의 확장이다. DP는 완전 탐색을, 다익스트라는 BFS와 큐를 기반으로 한다.

## 📝 학습 규칙

1. 하루 새 문제 1개 + 재풀이 1개를 기본 단위로 한다.
2. 30분간 자력으로 시도한 후, 해결되지 않으면 힌트를 확인한다.
3. 모든 문제를 재풀이 대상으로 둔다. 3~4일 간격으로, 코드를 보지 않고 새로 작성한다.
4. 각 문제의 `note.md`에 접근, 시간 복잡도, 막혔던 지점(문법 실수 포함)을 기록한다.
5. 개념을 익힐 때는 "어떤 문제 상황에 적용하는가"를 함께 정리한다.
6. 접근법이 떠오르지 않으면 효율성을 포기하더라도 정확성 통과를 우선 목표로 한다.

| `itertools` | 순열, 조합, 곱집합 |
| `math` | 최대공약수, 조합 계산 |

## 🔁 반복 구현 패턴

시험장에서 시간을 낭비하지 않도록 아래 패턴은 체화한다.

- 간선 리스트 → 인접 리스트 변환
- DFS 재귀 / BFS 큐 기본 골격
- 방문 처리 배열 관리 (반복 실행 시 초기화 주의)
- 노드 식별자가 문자열이거나 범위가 클 경우 배열 대신 해시맵 사용
- 단방향 / 양방향 그래프에 따른 간선 추가 분기
- 그리드(격자) 문제를 그래프로 치환하는 방식
